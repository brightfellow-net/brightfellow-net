# Contributing

Thanks for helping! This is the website for brightfellow.net. The same
guidelines are published on the site at `/community/#panduan`.

1. **Start with an issue.** Write down what you'd like to change and why
   first, so no work is done twice.
2. **Keep changes small and focused:** one thing per pull request.
3. **Explain how to test your change.** For this site, `npm run check` and
   `npm run build` must both pass.
4. **Licensing.** By sending a contribution, you agree that it is licensed
   under Apache-2.0, the same as the project.
5. **Be kind and patient.** We are all learning.

Security issues: please don't open a public issue. Email
hutomo@brightfellow.net with the subject "Security".
